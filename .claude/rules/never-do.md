# Never-Do Rules

- Never present an estimate, automated range or lead-form output as a formal valuation.
- Never publish a listing, price, location, image, credential or service claim without KV approval and a source of truth.
- Never upload, commit or retain titles, IDs, bank data, valuation reports or client exports in the repository.
- Never enable a CRM, analytics, map, messaging, email or payment integration without written approval for cost, data sharing and ownership.
- Never deploy, migrate inventory, change DNS or send client communications without Jay's explicit approval.
- Never expose an exact property location when KV's listing policy requires discretion.
- Never make response-time promises until KV confirms staffing and service-level ownership.
- Never broaden Phase 1 into a marketplace, AVM, native application or public property index without its PRD gate.
