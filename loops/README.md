# Automation Loops

An automation is eligible only when all four conditions are true:

1. Its trigger is explicit and observable.
2. Its inputs and permissions are known and approved.
3. Its success/failure result is measurable and recorded.
4. Its consequence is reversible or separately approval-gated.
